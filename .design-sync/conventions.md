## Как строить на этой системе

Дизайн-система «Мишка на сервере»: холодная приглушённая палитра catppuccin (Latte на свету, Macchiato в темноте) и ровно один акцент — Sapphire. Второго акцентного цвета в системе нет; если нужен ещё один цвет, это либо семантика callout, либо серия графика.

### Обёртка и тема

Компоненты стилизуются токенами с `:root`, поэтому в обычном приложении работают сразу после подключения `styles.css`. `ThemeProvider` нужен для переключения темы и обязателен для `ThemeToggle` (он вызывает `useTheme()` и без провайдера бросает исключение).

```jsx
<ThemeProvider defaultTheme="light">
  <SiteHeader nav={[{ label: 'Записи', href: '/posts', active: true }]} />
  <Container width="narrow">
    <PageHeader kicker="SRE" title="Burn-rate — что тут не так" meta="9 минут" />
    <Prose>…</Prose>
  </Container>
</ThemeProvider>
```

`mode="global"` (по умолчанию) ставит `data-theme` на `<html>`. `mode="scoped"` ставит его на собственный контейнер — так светлая и тёмная версии живут на одной странице.

### Идиома стилей: CSS-переменные, не утилиты

Утилитарных классов в системе нет. Своя вёрстка вокруг компонентов пишется обычным CSS через переменные — никаких хардкод-хексов и произвольных пикселей.

| Роль | Токены |
|---|---|
| Поверхности | `--bg`, `--bg-elev`, `--bg-sunken` |
| Текст | `--fg`, `--fg-muted`, `--fg-subtle` |
| Акцент | `--accent`, `--accent-hover`, `--accent-soft`, `--accent-300`, `--accent-400`, `--accent-600`, `--accent-700` |
| Границы | `--border`, `--border-strong` |
| Код | `--code-bg`, `--code-fg`, `--code-inline-bg` |
| Семантика | `--c-note`, `--c-tip`, `--c-important`, `--c-warn`, `--c-danger` (+ `-text` версии для заголовков) |
| Графики | `--chart-1` … `--chart-8` |
| Синтаксис | `--syn-keyword`, `--syn-string`, `--syn-number`, `--syn-constant`, `--syn-comment`, `--syn-function`, `--syn-type`, `--syn-variable`, `--syn-operator`, `--syn-meta` |
| Кегль | `--fs-xs` … `--fs-4xl`, плюс `--fs-display-sm/md/lg` |
| Отступы | `--gap-xs`, `--gap-sm`, `--gap-md`, `--gap-lg`, `--gap-xl`, `--gap-2xl` |
| Радиусы | `--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-pill` |
| Шрифты | `--font-sans`, `--font-mono`, `--font-serif` |
| Ширины | `--content-width` (720px), `--container-width` (1200px) |

Пример своей обвязки:

```jsx
<div style={{
  display: 'grid', gap: 'var(--gap-md)',
  padding: 'var(--gap-lg)',
  background: 'var(--bg-elev)',
  border: '1px solid var(--border)',
  borderRadius: 'var(--radius-md)',
}}>
  <Callout type="warn" title="Осторожно">…</Callout>
</div>
```

### Жёсткие правила

- **Текст-ссылка на светлом фоне — только `--accent-700`.** `--accent-400` декоративный: бордеры, иконки, кавычка в крупной цитате. `--accent-600` — крупный кегль, не body-текст.
- **Вертикальных акцентных полосок слева в системе нет.** Ни у врезок, ни у цитат, ни у заголовков, ни у карточек. Блок выделяется заливкой, тонкой рамкой по периметру и иконкой; заголовок секции — линейкой под строкой; закреплённая карточка — рамкой в акценте. `border-left: 3px solid` — приём, который из этой системы убрали намеренно, не воспроизводить.
- **Display-ступени только для слайдов.** `--fs-display-*` в вёрстке страницы не применять.
- **Цвет не единственный носитель смысла.** У `Callout` есть иконка и заголовок, у `ProjectCard` статус подписан словом, у линии графика должна быть подпись — акцентные тона catppuccin лежат в узкой полосе яркости и в ч/б не различаются.
- **Проза не набирается моноширинным.** `--font-mono` — код, `InlineCode`, `Kbd`, технические метки, контакты на визитке.

### Что где брать

Слайды — `Slide`, `SlideCover`, `SlideSection`, `SlideFact`, `SlideStatement`, `SlideQuote`, `SlideBullets`, `SlideTwoCols`, `SlideOutro`, обёртка `Deck`. Холст 16:9, одно акцентное пятно на слайд.

Печать — `Sheet` (лист A4 с полями 18 мм) и `BusinessCard` (90×50 мм с вылетами). Визитка печатается из документа, объявляющего свой `@page`.

Обвязка сайта — `SiteHeader`, `SiteFooter`, `BearMark`, `ThemeToggle`.

Цитаты разведены по весу, а не по цвету: `Quote` — короткая ссылка на чужие слова в потоке, с заливкой; `ThinPlace` — смысловая остановка, крупный кегль с открывающей кавычкой и без заливки. Тире перед автором ставит CSS, в контент его писать не нужно.

`CodeBlock` красит код через `highlight.js`, если тот доступен, и берёт цвета из `--syn-*`. Не доступен — рендерит простой текст, это рабочее состояние.

Точные значения токенов — в `styles.css` и файле `_ds_bundle.css`, который он импортирует: там же лежат и стили компонентов. API каждого компонента — в его `.d.ts`, примеры использования — в `.prompt.md` рядом. Читать их надёжнее, чем угадывать.
